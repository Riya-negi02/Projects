Employee Management System 👩‍💼👨‍💼

The Employee Management System (EMS) is a Python-based project that allows users to efficiently manage employee details. It provides options to add, view, update, search, and delete employee records, making it useful for small businesses or educational learning projects.

🚀 Features

Add new employees with details (ID, Name, Department, Salary, etc.)

View all employee records in a structured format

Search employees by ID, name, or department

Update existing employee details

Delete employee records

Persistent data storage using files (JSON )

🛠️ Tech Stack

Programming Language: Python (≥3.7)

Storage: JSON 

📂 Project Structure
EmployeeManagementSystem/
│
├── employee_management.py     # Main program file
├── employees.json             # Stores employee data (auto-created)
├── README.md                  # Documentation

Run the program:

python employee_management.py
